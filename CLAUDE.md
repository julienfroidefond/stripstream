# CLAUDE.md

The canonical repository and agent guidance for Stripstream lives in
[`AGENTS.md`](./AGENTS.md). Claude Code must follow that file.

`AGENTS.md` is the single source of truth for project structure, commands,
testing, architecture, conventions, and quality gates. Do not duplicate its
content here. When guidance changes, edit `AGENTS.md` so the two files cannot
drift apart again.

For system internals see [`docs/architecture.md`](./docs/architecture.md); for
the API surface see [`docs/api.md`](./docs/api.md). The documentation index is
[`docs/README.md`](./docs/README.md).
